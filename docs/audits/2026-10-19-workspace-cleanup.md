# Workspace cleanup and publication preparation

Date: 19 October 2026, Asia/Jakarta. Checkout: VERA, Windows x64.

## Scope and organization

Existing uncommitted research-workflow implementation, dashboard changes, and
Windows packaging work were retained and checked for publication. No research
feature, academic connector, execution backend, or compatibility setting was
removed as cache cleanup.

- Research implementation reports moved from `docs/vera-revision/` to
  `docs/research-workflow/`.
- The original `VERA_Workflow_Codex_Pack/` specification moved into
  `docs/research-workflow/specification/`.
- Earlier UI reports and screenshots moved into `docs/design-history/`;
  `ui/design-previews/` moved into its `previews/` subfolder. The archived HTML
  prototype references the checkout's stylesheet with a relative path.
- Earlier demo workflow notes moved to `docs/research-workflow/legacy-demo.md`.
- `docs/README.md` indexes the documentation. `docs/maintenance.md` documents
  generated outputs, retained source/data, and cleanup commands.
- `.gitignore` covers disposable Vite/router/test caches and temporary files.
  `.gitattributes` marks `ui/dist` as generated and exempts its dependency strings
  from source whitespace checks; the bundle remains generated by Vite.
- `scripts/clean-workspace.ps1` previews by default, checks containment and Git
  tracking, refuses active build/app cleanup, and preserves reparse points.
  Its fixture safety test is included in Windows CI.

## Cleanup results

The applied inventory removed **39,078 ordinary files**, totaling
**10,468,661,158 bytes** (10.47 GB; 9.75 GiB). These are logical file sizes,
not a measurement of filesystem allocation or a guarantee of the exact change
in free disk space.

Removed categories:

- Rust outputs, incremental/check caches, obsolete installer staging/downloads,
  cached packaging tools, isolated test profiles, temporary reports/screenshots,
  and ad hoc debug scripts under `target/` and `windows/launcher/target/`.
- Disposable Vite/tool caches, router scratch output, and TypeScript build state.
- Superseded executable/installer copies under `dist/backups/` after verifying
  the retained current distribution.
- Named HTTP/code/GPU/shader caches in VERA's own WebView profile.
- An empty stale `.git/index.lock` dated 14 October, after inspecting Git
  processes; this allowed normal staging again.

Three Windows-created `Content.IE5` junctions remain under the isolated profiles
`target/package-smoke-20261014-221223/`, `target/package-smoke-20261018-214826/`,
and `target/package-smoke-20261019-011325/`. Automatic approval review rejected
unlinking old fixture junctions. Cleanup instead skipped every junction and
removed ordinary siblings without traversing the links.

Configuration/database fingerprints for **18 files** were equal before and
after cleanup. User research data, configuration, agent homes/session state,
WebView local storage/IndexedDB/cookies, historical OpenResearch paths, installed
development dependencies, and the committed dashboard bundle were retained.
Shared Chrome/Edge browser caches were outside this app-specific cleanup.
